# CariKeras — Main Website

The public homepage for the CariKeras ecosystem.

## Domain

- Production: https://cari.cc.cd
- Repository: https://github.com/carikeras/cari

## Stack

- Static HTML
- Bootstrap 5
- CariKeras UI via jsDelivr
- Small vanilla JavaScript layer
- Cloudflare Pages compatible
